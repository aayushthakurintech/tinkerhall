# Tinkerhall studio plugin

A tiny software studio for people who are not experts. Run `/studio:start` in an
empty folder and describe the app you want in plain words. A Producer asks you a
few simple questions, then hands work to five helpers: a Planner writes a
one-page brief, a Designer plans the screens and look, a Builder builds one small
slice at a time, a Tester runs it and shows real output, and a Reviewer checks
quality, accessibility and basic security. You approve the brief and the design,
and you get a hand-over note that says what works and what does not.

Install it in Claude Code with:

```text
/plugin install studio --marketplace aayushthakurintech/tinkerhall
```

This plugin is Markdown instructions only. It has no hooks, MCP servers, scripts
or binaries.

See the [main README](../../README.md) for install steps, safety notes and limits.
